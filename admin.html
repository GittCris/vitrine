Opções avançadas (só se der erro ao entrar)
Como gerar o token (uma vez só):
  1. No GitHub: Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  2. Em Repository access, escolha Only select repositories e marque só o repositório da vitrine.
  3. Em Permissions → Repository permissions, coloque Contents: Read and write.
  4. Gere, copie o token e cole acima.

Depois de salvar, o site leva cerca de 1 minuto para mostrar a mudança.
